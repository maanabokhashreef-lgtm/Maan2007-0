## 📖 نظرة عامة

Med~Final~Study تطبيق ويب يحوّل فوضى نهاية الفصل الدراسي إلى خطة واضحة:

1. **سجّل موادك وامتحاناتك** — عد تنازلي حي بالثانية لكل امتحان.
2. **ولّد خطتك بضغطة** — خوارزمية التوزيع الموزون تقسم سلايداتك على الأيام بعدالة وذكاء.
3. **ذاكر مع المؤقت أو البومودورو** — كل دقيقة تُسجل وتغذي إحصائياتك وسلسلة التزامك.
4. **تابع جاهزيتك بدقة** — تقدير ذكي (A/B/C) ووتيرة يومية تنبئك بالتأخر قبل فوات الأوان.
5. **انظر للمستقبل عبر التقويم** — امتحاناتك ومراجعاتك المتباعدة (7 و3 ويوم قبل كل امتحان) في شبكة شهرية واحدة.

جميع البيانات تُحفظ **محلياً على جهازك (localStorage)** — بلا خوادم، بلا حسابات، بلا تتبع.

## ✨ الميزات الكاملة (v3)

### 🧠 الخوارزميات الذكية (الجديد)
| الخوارزمية | ماذا تفعل؟ |
|---|---|
| **المولد الذكي للخطط** | توزيع موزون: أيام البداية أثقل (استيعاب المادة)، والأيام الأخيرة أخف (مساحة مراجعة)، مع استبعاد أيام راحة تختارها، وتقسيم السلايدات بطريقة «أكبر البقايا» العادلة، وربط كل يوم بنطاق شابتراته |
| **أولوية اليوم** | بطاقة «ماذا تذاكر اليوم؟» تحسب لكل مادة درجة = إلحاح الامتحان 60% + عجز الجاهزية 40%، وتقترح هدف اليوم من الجدول الذكي |
| **الوتيرة وتوقع التأخر** | تقارن وتيرتك الحالية (سلايد/يوم) بالمطلوب للوصول بالوقت: على المسار ✓ / متأخر ⚠ مع العدد المطلوب |
| **المراجعات المتباعدة** | تحديد تلقائي لثلاث مراجعات قبل كل امتحان (بـ 7 و3 ويوم واحد) تظهر في التقويم والبطاقات |
| **تقدير الجاهزية الذكي** | نتيجة مركبة = تغطية الوقت 65% + إنجاز أيام الجدول الذكي 20% + انتظام السلسلة 15% ← تقدير A ممتاز / B جيد جداً / C جيد / يحتاج تركيز |
| **بومودورو** | دورات تركيز 25 د (قابلة للتخصيص) مع استراحة قصيرة كل جلسة وطويلة كل 4 جلسات، تُسجل تلقائياً في إحصائيات اليوم وفي الخطة المرتبطة |

### 📅 جدول الامتحانات
- إضافة مواد مع التاريخ والوقت والشابترات والسلايدات + حساب سلايد/شابتر.
- عد تنازلي حي يتلون وينبض عند الاقتراب (أقل من يومين).
- عمود الوتيرة مع شارة ملونة، وشارة التقدير الذكي في عمود الاستعداد.
- بحث فوري + ترتيب (تاريخ/سلايدات/أبجدي) + زر **طباعة الجدول**.
- **ملاحظات لكل مادة** (نقاط ضعف، أجزاء مهمة) بعلامة ذكية في الجدول.
- تعديل بنافذة أنيقة، وحذف بتأكيد مع تحذير من الخطط المرتبطة.
- منع التكرار والتواريخ الماضية.

### 📖 خطة المذاكرة
- إنشاء يدوي بملء تلقائي للتواريخ + معاينة حية (أيام × ساعات = إجمالي + هدف سلايدات).
- **زر المولد الذكي** من التبويب أو من صف أي مادة.
- مؤقت لكل خطة (بدء/إيقاف/تصفير) يستمر بالحساب حتى بعد إغلاق الصفحة.
- **الجدول الذكي داخل بطاقة الخطة**: قائمة أيام قابلة للطي، علّم كل يوم عند إنهائه، صف اليوم مميز بلون ذهبي.
- فلاتر (الكل/قيد المذاكرة/مكتملة) + بحث + شارات «ذكية» و«مكتملة» و«يعمل».

### 🗓️ التقويم (الجديد)
- شبكة شهرية تنقّل بين الأشهر مع زر «اليوم».
- تمييز ملون: امتحان (وردي)، مراجعة متباعدة (ذهبي)، يوم خطة (زمردي)، اليوم (إطار ذهبي).
- لوحة تفاصيل اليوم: الامتحانات بأوقاتها، المراجعات، وأهداف الجدول الذكي مع تعليمها مباشرة من التقويم.

### 📊 الإحصائيات والإنجازات
- بطاقات عدّ متحرك + رسم أعمدة لساعات آخر 7 أيام + حلقة إتمام الخطط.
- قائمة الجاهزية الذكية لكل مادة مع التقديرات.
- **16 إنجازاً** تُفتح تلقائياً مع احتفال confetti، وسلسلة التزام اليومية 🔥 مقابل هدف يومي قابل للتخصيص.

### ⚙️ الإعدادات والبيانات
- وضع داكن/فاتح، هدف يومي (15–720 دقيقة)، **تخصيص دقائق البومودورو** (تركيز/استراحة/طويلة).
- تنبيهات المتصفح قبل الامتحان بأقل من 24 ساعة.
- تصدير/استيراد نسخة احتياطية JSON (تشمل الجداول الذكية وجلسات البومودورو).
- بيانات تجريبية، مسح شامل بتأكيد مزدوج، ترحيل تلقائي للنسخ الأقدم.

### 🎨 الهوية البصرية v3
- **ألوان جديدة كلياً**: زمردي ملكي (#0d9488 → #059669) + ذهبي ملكي (#d9a13b) على خلفيات عاجية/غابية.
- **خطوط جديدة فاخرة**: El Messiri للعناوين، Alexandria للنصوص، Scheherazade New للآية القرآنية.
- خلفية **Aurora** متحركة (فقاعات زمردية/ذهبية/سماوية تنساب ببطء) + نسيج ضجيج دقيق يضيف عمقاً فنياً.
- زجاجية (Glassmorphism)، تدرجات ذهبية في الترويسة والبطاقات المميزة، أيقونات SVG مرسومة يدوياً (35+).
- حركات مدروسة في كل تفاعل: دخول متدرج، نبض العد التنازلي، توهج البومودورو، دوران الحلقات.
- **دعم كل الأحجام**: خط سائل clamp() وشبكات مرنة — مختبر فعلياً بلا أي تمرير أفقي عند 320 / 375 / 414 / 768 / 1024 / 1366px، مع إخفاء نصوص التبويبات لصالح الأيقونات تحت 340px.
- أنماط **طباعة** نظيفة للجدول والخطط، ودعم `prefers-reduced-motion` ووصولية كاملة (aria، Esc، لوحة مفاتيح).

## 🚀 النشر على Netlify

### السحب والإفلات (دقيقتان)
1. فك ضغط الملف، ثم افتح <https://app.netlify.com/drop>.
2. اسحب مجلد `med-final-study` وأفلته — منشور فوراً على رابط HTTPS.
3. غيّر الاسم من `Site settings → Site details → Change site name`.

### عبر GitHub
1. ارفع المجلد لمستودع، ثم في Netlify: **Import an existing project**.
2. الإعدادات تأتي جاهزة من `netlify.toml` (publish = `.` وبلا build) — كل push يعيد النشر تلقائياً.

### التشغيل محلياً
```bash
cd med-final-study
python3 -m http.server 8080    # ثم افتح http://localhost:8080
```

## 🛠️ التعديل وإعادة البناء
```bash
npm install      # مرة واحدة
npm run build    # يعيد توليد js/ من src/
npm run serve    # معاينة محلية
```

| التخصيص | المكان |
|---|---|
| الألوان | متغيرات `:root` في `css/style.css` |
| الخطوط | وسم الخطوط في `index.html` + `--font-*` في CSS |
| أوزان الخوارزمية (إلحاح/عجز) | `Algo.todayFocus` في `src/algo.jsx` |
| معادلة التقدير الذكي | `Algo.readinessGrade` |
| أوزان توزيع الأيام | `Algo.weightedSchedule` |
| مدد البومودورو الافتراضية | `Algo.POMO_DEFAULTS` |
| الكليات / العبارات / الإنجازات | `src/core.jsx` |
| الشعار الرسمي | ضع صورة في `assets/` وحدّث المسار في `src/screens1.jsx` |
